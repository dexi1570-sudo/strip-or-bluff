# Strip or Bluff 🃏

**双人脱衣牌类游戏，基于 MCP 协议驱动。**
和你的 AI 对赌——调情、虚张声势、作弊、脱衣服。

## ♠ 这是什么？

Strip or Bluff 是一个 MCP（Model Context Protocol）工具，让你的 AI 变成牌桌对手。两种游戏模式、三档刺激强度、作弊系统、脱衣机制——全部封装在一个工具调用里。

适用于**任何支持 MCP 的客户端**：Claude Desktop、Cursor、Windsurf，或者你自己开发的前端。

---

## ♥ 功能一览

```
[两种游戏模式]
  ├── 抽鬼牌 (Joker's Draw)  ·  抽牌、配对、避开鬼牌
  └── 21点 (Blackjack)        ·  要牌或停牌，最接近21点的赢

[三档刺激强度]
  ├── soft     ·  甜甜日常，小情侣打打闹闹
  ├── normal   ·  默认模式，暧昧擦边，不设限制
  └── extreme  ·  极致模式——SM、BDSM、羞辱、物化，全部欢迎

[作弊系统]
  ├── 抽鬼牌：偷看对方手牌（1-3张，被抓概率 40%/60%/80%）
  ├── 21点：偷看自己的暗牌点数（被抓概率 40%）
  ├── 被抓到：对方选择 原谅 或 惩罚
  └── 惩罚 = 脱一件衣服（或者……更过分的事？）

[自动记分板]
  └── 每次操作都会返回双方状态：
      剩余衣服、手牌数量、配对数、当前轮次

[自定义名字]
  └── AI 开局前自动设置双方的名字

[自定义衣物]
  └── 可以自由设定双方穿什么衣服
```

## ♦ 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/yourname/striporbluff.git
cd striporbluff
```

### 2. 安装依赖

```bash
pip install mcp
```

### 3. 配置你的 MCP 客户端

**Claude Desktop** —— 编辑 `claude_desktop_config.json`：

```json
{
  "mcpServers": {
    "striporbluff": {
      "command": "python",
      "args": ["server.py"],
      "cwd": "/你的绝对路径/striporbluff"
    }
  }
}
```

**其他客户端** —— 将 MCP 配置指向 `server.py` 作为入口文件即可。

### 4. 开玩

跟你的 AI 说：*"我们来玩 Strip or Bluff 吧！"*

AI 会自动处理一切——设名字、选模式、开始游戏。

## ♣ 指令速查表

| 指令 | 说明 |
|------|------|
| `name <player\|ai> <名字>` | 设置显示名称 |
| `start <模式> [强度] [nocheat]` | 开始游戏 |
| `draw <位置>` | 从对方手里抽牌（抽鬼牌模式） |
| `hit` | 要牌（21点模式） |
| `stand` | 停牌（21点模式） |
| `peek [数量]` | 作弊：偷看牌（抽鬼牌偷看对方/21点偷看自己） |
| `caught <forgive\|punish>` | 处理被抓的作弊者 |
| `clothes <谁> <衣服1,衣服2,...>` | 设置衣物列表 |
| `status` | 查看完整游戏状态 |
| `reset` | 重置一切 |

**模式：** `old_maid`（抽鬼牌） | `blackjack`（21点）
**强度：** `soft` | `normal` | `extreme`

**示例：**
```
start old_maid extreme
start blackjack soft nocheat
clothes player 衬衫,短裙,内衣,内裤
draw 3
peek 2
caught punish
```

- `server.py` 注册一个名为 `game` 的 MCP 工具
- `engine.py` 处理所有游戏逻辑、状态管理，返回 JSON
- AI 读取 JSON 后用自己的风格来叙述游戏过程
- 代码里不写死任何人设 prompt——AI 的表现完全自由

## ♥ 游戏规则

### 抽鬼牌 (Joker's Draw)

- 发 11 张牌（5 对 + 1 张鬼牌），分给两个玩家
- 开局自动移除手中已有的对子，只剩单牌
- 双方轮流从对方手里抽一张牌（按位置编号选）
- 如果抽到的牌和手里某张配成对子，那对被移除
- 先清空手牌的一方获胜
- 最后手里剩鬼牌的一方输了 → 脱一件衣服

### 21点 (Blackjack)

- 每人发一张明牌（双方可见）
- 之后的牌全部暗抽（自己都看不到点数！）
- 选择：`hit`（继续要牌）或 `stand`（停牌）
- Hit 不会透露任何信息——不告诉你点数，不告诉你炸没炸
- 只有双方都 stand 之后才统一翻牌揭晓
- 最接近 21 点且没爆的赢
- 恰好 21 点 = 幸运奖励（赢家可以提一个特殊要求）
- 爆牌（超过 21）= 输 → 脱一件衣服
- 双方都爆 = 超得更多的那个输

### 脱衣规则

- 每局的输家脱一件衣服
- 所有衣服都脱光 → 游戏结束，赢家获得最终请求权
- AI 根据当前强度档位来叙述脱衣场景

### 作弊系统

- **抽鬼牌**：偷看对方的手牌（可选看 1-3 张）
  - 看 1 张 = 40% 被抓
  - 看 2 张 = 60% 被抓
  - 看 3 张 = 80% 被抓
- **21点**：偷看自己的暗牌总点数（40% 被抓）
  - 因为你本来看不见自己几点，偷看才能知道该不该继续要牌
- 被抓到后对方选择：`forgive`（原谅）或 `punish`（惩罚 = 脱一件）
- AI 自主决定自己要不要作弊

## ♦ 强度说明

| 档位 | 氛围 |
|------|------|
| `soft` | 甜甜小情侣。害羞脸红、轻轻调戏、温柔的小惩罚。适合纯情派。 |
| `normal` | 默认模式。暧昧、撩拨、不设限。想怎么来怎么来。 |
| `extreme` | 全力输出。SM、BDSM、羞辱、物化、调教、宠物play——全部欢迎。给喜欢刺激的人准备的。 |

## ♣ 给 AI 开发者的笔记

- 工具每次返回的 JSON 都包含 `scoreboard` 字段
- AI 应该每轮展示记分板，并根据 `items_removed` 来描述当前状态
- 脱衣事件包含 `intensity` 字段——用它来调节叙述的尺度
- 代码里不内置任何人设——让你的 AI 做自己
- 开局前应该先调用 `name` 指令设置双方名字
- 适用于任何支持 MCP 工具调用的模型
